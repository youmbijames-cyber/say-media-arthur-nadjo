# SAY MEDIA — Site vitrine Arthur Nadjo Youmbi

Site one-page moderne pour l'entretien d'embauche chez **SAY MEDIA** (agence de communication, Douala / Yaoundé).

## Contenu

- **Hero** — Nom, accroche « Transformer la créativité de SAY MEDIA en revenus mesurables », compteurs animés
- **Impact** — 3 cartes glassmorphism (Prospection Data-Driven, Dashboard, Pont Chine)
- **Timeline Chine** — Avant / Pendant / Après
- **Compétences** — Barres de progression animées
- **Footer** — Contact + disponibilité

## Stack

- HTML5 sémantique
- CSS3 (dark mode, glassmorphism, animations, responsive)
- JavaScript vanilla (typewriter, particules canvas, IntersectionObserver, curseur custom)

## Lancer en local

Ouvrir `index.html` dans un navigateur, ou :

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

Puis aller sur `http://localhost:8000`.

## GitHub Pages

1. Repo → **Settings** → **Pages**
2. Source : **Deploy from a branch**
3. Branch : **main** / folder : **/ (root)**
4. Save → le site sera en ligne sous  
   `https://youmbijames-cyber.github.io/say-media-arthur-nadjo/`
